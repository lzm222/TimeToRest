# Time To Rest

<img alt="Time To Rest Logo" height="256" src="src/main/resources/logo.png" width="256"/>

## Description
This is a Minecraft mod running on NeoForge loader which to remind you
to take a rest after you play for a long while.

## Download

### From release
You can download this mod from [GitHub Releases](https://github.com/lzm222/TimeToRest/releases).

### Build from source code
1. Make sure you have Java version 21 or above installed.
2. Clone this repository  

    ```shell
    git clone github.com/lzm222/TimeToRest
    ```

3. Run Gradle build command  

    ```shell
    cd TimeToRest
    ./gradlew build
    ```
